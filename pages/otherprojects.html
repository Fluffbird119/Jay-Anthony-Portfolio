New Scene Game Jam 2025 / Hello World Hackathon 2025

• Me and a friend made this game during the New Scene Gam Jam 2025 but submitted it to both the game jam and the Hello World Hackathon that was going on at the same time.
• I did programming and UI while he did level design and audio.
• I designed the player to have an incredibly strong jump force so that they'd be able to move the cage easily.
• It took a lot of tweaking to make the game feel good but it turned out well. The movement feels clunky because you are in the cage but fair and learnable if you put the time into figuring out the level.

Congressional App Challenge 2024

• The Federal Reserve publishes huge text files that document how many times each active member of congress traded stocks that year.
• Since I was participating in the Congressional App Challenge I thought it would be ironic if I made an app that dealt with an issue quite pertinent to Congress.
• I wrote my own database and data parser that could read in the data straight from the Federal Reserve disclosure documents in Python.
• This was my first project working with a large amount of text data so figuring out how to parse it and make it user friendly was a challenge but I succeeded in it.
